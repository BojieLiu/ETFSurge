fix(fetcher): correct two broken relative imports in china_market.py

Root cause of all factor data being 0.0:

1. line 255: from .source_registry import registry (absolute within fetchers/)
   → should be "from ..services.source_registry import registry"
   source_registry is in app/services/, not app/fetchers/

2. line 275: from .utils import no_proxy (absolute within fetchers/)
   → should be "from ..utils.proxy import no_proxy"
   utils is at app/utils/, not app/fetchers/

Both imports failed silently (caught by try/except in _sina_history_cb),
causing fetch_history() to return empty data for ALL symbols. This meant
ALL 26 factor values (technical, momentum, valuation, sentiment) were 0.0.

After fix: 10/10 technical factors LIVE (was 2/10), 3/10 momentum LIVE
(was 1/10), 2/2 valuation LIVE (was 0/2). Only sentiment still at 0/4
(needs news cache bridging, tracked separately).

The single import bug explains EVERY data pipeline failure observed:
- No OHLCV data → flat factor scores → same ETF picks for all strategies
- Empty pool after scanner failure (secondary: scanner returns empty,
  then refresh wipes pool)

Remaining known gap: Valuation variance > 0.01 (all symbols get 100e9
fallback because symbol_extra with fund_scale is only available when
called through pool_manager, not standalone FactorRegistry).
