fix: run_sync wrappers + fire-and-forget market snapshot

Root cause of backend hangs during design/strategy-check tasks:
- scanner.full_pipeline() and classifier.batch_classify() ran
  synchronously on the event loop thread, blocking all async handlers
  including /health
- _refresh_market_snapshot() was awaited at end of refresh(), but
  called compute_sector_momentum which uses additional run_sync calls,
  delaying refresh() completion
- compute_sector_momentum had a direct synchronous akshare call
  (already fixed in 411aee7)

Fixes:
- Wrap scanner.full_pipeline() in await run_sync() -> thread pool
- Wrap classifier.batch_classify() in await run_sync() -> thread pool
- _refresh_market_snapshot changed to asyncio.create_task() ->
  fire-and-forget, doesn't block refresh()
